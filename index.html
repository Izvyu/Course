嗨翻

日本宮古島五天四夜｜海島玩好玩滿、一起嗨翻！

行前提醒 開團必看！⚡

  • 天氣

    示意：晴時多雲、海邊日照強；出發前再看天氣預報。

  • 要帶的東西

    示意：防曬乳、帽子、泳衣、海灘鞋和行動電源。

  • 集合時間

    示意：第一天 10:00，在宮古機場到達大廳集合。

  • 集合地點

    桃園國際機場

第一天 抵達宮古・南島海灘

  1. 10:00

    宮古機場

    示意抵達時間，取車後先到市區放行李、補給飲水。

  2. 12:00

    示意午餐店 A・平良市區

    先用示意店名安排第一餐，嚐嚐島上的沖繩料理。

  3. 14:00

    與那霸前濱海灘

    踩踩細白沙、看看透亮的海色，開啟宮古藍模式。

  4. 17:00

    來間島・龍宮城展望台

    登上展望台，把前濱海灘和來間大橋的景色一次收進眼裡。

第二天 砂山海色・池間島兜風

  1. 09:00

    砂山海灘

    沿著沙丘步道走到海邊，欣賞珊瑚岩洞和藍色海灣。

  2. 11:30

    池間大橋

    開上跨海大橋看海水漸層，找安全停車點再拍照。

  3. 12:30

    示意午餐店 B・池間島

    用示意店名留一段午餐時間，試試島上漁獲或宮古麵。

  4. 15:00

    西平安名崎

    到島嶼北端吹吹海風，遠望池間島與伊良部島。

第三天 伊良部大橋・下地島探險

  1. 09:00

    伊良部大橋

    沿著跨海大橋開往伊良部島，沿途欣賞宮古藍全景。

  2. 10:30

    通池

    沿步道探訪兩座相連的海蝕池，看看獨特的地形景觀。

  3. 12:30

    示意午餐店 C・伊良部島

    在伊良部島安排一頓示意午餐，吃飽再繼續兜風。

  4. 15:00

    17END・下地島

    在海邊步道欣賞清澈海色，留意現場公告與飛機起降狀況。

第四天 東海岸秘境・南島海灣

  1. 09:00

    東平安名崎

    沿著狹長岬角散步，欣賞兩側海景和白色燈塔。

  2. 11:30

    吉野海岸

    在珊瑚礁海岸看看海底生態，水上活動依潮汐與現場狀況安排。

  3. 13:30

    示意午餐店 D・城邊地區

    以示意店名預留午餐時段，吃完稍作休息再出發。

  4. 15:30

    印加瑪海濱公園

    逛逛被海灣環抱的步道和展望點，享受悠閒的午後。

第五天 平良市區・收心返程

  1. 09:00

    示意早餐店 E・平良市區

    用最後一頓示意早餐慢慢開機，再整理行李退房。

  2. 10:30

    宮古神社與平良市街

    在市區散步買伴手禮，為旅程補上最後一站小巡禮。

  3. 12:00

    示意午餐店 F・平良市區

    用示意店名安排返程前的午餐，店家之後再換成真的。

  4. 14:00

    宮古機場・返程

    預留還車和報到時間，實際抵達時間依航班調整。
